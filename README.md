## 1. Project Objectives
A full-stack cloud application managing employee shifts, attendance logging, leave approval workflows, and mandatory compliance reports.

## 2. Technology Stack
- **Frontend:** HTML5, Tailwind CSS, JavaScript (ES6+)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas (Cloud NoSQL)
- **Containerization & Orchestration:** Docker, Kubernetes
- **Deployment:** Render Web Services

## 3. Features & Screens (9 Screens)
1. Overview Dashboard
2. Mark Attendance (Punch In / Punch Out)
3. Apply Leave (Casual, Sick, Earned)
4. Leave Approvals (Manager review workflow)
5. Shift Scheduling (Morning, General, Night shifts)
6. Holidays Calendar (Mandatory / Company holidays)
7. Employee Directory (Workforce registry with leave quotas)
8. Mandatory Reports (4 audit-ready statutory reports)
9. User Profile (Credentials & role access)

## 4. Mandatory Reports Implemented
- Attendance Summary Report
- Leave Balance Report
- Shift Roster Report
- Absenteeism Report
